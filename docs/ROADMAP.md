# ORYBIT Roadmap

## Phase 0 — Foundation

Define:

- product vision
- engineering principles
- architecture
- object schema
- event schema
- capability schema
- ADRs
- protocol SDK
- runtime validation

## Phase 1 — Object Registry

Build:

- object creation
- object persistence
- object lookup
- management dashboard
- REST object API
- D1 persistence adapter
- automated registry tests

## Phase 2 — Universal Object Page

Build:

- mobile-first public object view
- public/private field boundaries
- object status

## Phase 3 — Physical-to-Digital Bridge

Build:

- QR generation
- QR resolution
- NFC-compatible URI strategy
- carrier registration

## Phase 4 — Object Memory

Build:

- event timeline
- maintenance events
- lifecycle events
- immutable historical records where appropriate

## Phase 5 — Ownership

Build:

- owner association
- ownership history
- ownership transfer
- privacy controls

## Phase 6 — Capability Engine

Build:

- capability registry
- capability discovery
- capability-driven UI
- access classifications

## Phase 7 — Object Manifest

Publish:

- machine-readable object manifest
- JSON Schema
- protocol specification
- reference examples

## Phase 8 — Developer Platform

Build:

- REST API
- SDK
- API authentication
- developer documentation
- example integrations

## Phase 9 — PermissionOS

Build:

- scoped authorization
- temporary access
- action approval
- audit history

## Phase 10 — Reality API

Research and prototype:

- standardized physical capabilities
- manufacturer adapters
- device abstractions
- common action semantics

## Phase 11 — Intelligence Layer

Explore:

- local/open AI models
- diagnostics
- natural-language object interaction
- contextual assistance

## Phase 12 — Ecosystem

Explore:

- manufacturer tooling
- developer ecosystem
- additional carriers
- interoperability
- standards participation
